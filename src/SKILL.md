# 麦门人格鉴定所

把用户的麦当劳历史订单变成一张值得截图分享的人格鉴定卡。数据全部来自麦当劳官方 MCP（mcd-mcp），无订单数据时自动切换演示模式，评委与零订单用户也能零门槛体验。

## 前置条件

- 用户已在 WorkBuddy 连接器管理中配置并信任 `mcd-mcp`（Token 申请入口：open.mcd.cn/mcp，手机号登录后在控制台激活复制）
- 本 Skill 为纯标准库 Python 3.8+，无第三方依赖

## 工作流

1. **确认模式**
   - 用户能提供 Token → 真实模式：`python src/run.py --token <TOKEN>`
   - 用户无 Token / 无订单历史 → 演示模式：`python src/run.py --demo`
2. **生成鉴定卡**：运行入口脚本，stdout 返回 JSON 摘要（人格类型、五维分数、产物路径）
3. **呈现结果**：把输出的 HTML 鉴定卡路径展示给用户；如用户要求分享文案，用人格 slogan + 判词金句各截一句
4. **解读口径**：向用户说明——五维分数（犒赏力/猎奇度/夜猫指数/辣度耐受/甜度依赖）由订单频次、客单、品类占比、下单时段计算；营养数字为公开数据 × 点单量估算，仅供娱乐

## 降级与边界

- MCP 网络失败或 Token 失效 → 脚本自动回落 `--demo` 并在 stderr 告警，不要把失败伪装成真实结果
- 订单不足 3 单 → 输出「麦门新信徒」待鉴定卡，并引导用户下首单后再测
- 不下单、不改地址、不操作优惠券：本 Skill 只读订单/账户/营养三类接口

## 文件说明

- `src/run.py` — 入口（CLI）
- `src/mcd_client.py` — mcd-mcp JSON-RPC 客户端（含 markdown 解包）
- `src/analyze.py` — 人格引擎（指标计算 + 九型人格判定 + 营养彩蛋）
- `src/report.py` — 单文件 HTML 鉴定卡渲染
- `src/taxonomy.py` — 餐品品类与标签规则
- `src/demo_data.py` — 演示合成数据（seed=1024 可复现）
